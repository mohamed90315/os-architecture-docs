## 📖 Repository Overview

This repository houses all the documentation, requirements, course plans, and graphical assets associated with the Operating Systems coursework.

It serves as the academic foundation for the code implemented in the sister repository: [os-process-sync](https://github.com/mohamed90315/os-process-sync).

## 📂 Directory Layout

* **`docs/`**: Contains the core academic documents.
  * *Project requirements and specifications.*
  * *Transcripts and academic history.*
  * *Course plans for CS, AI, IS, SE, CY.*
* **`assets/`**: Contains visual diagrams and images.
  * *`img_1/` & `img_2/`: Snapshots and output references for various coding tasks.*
